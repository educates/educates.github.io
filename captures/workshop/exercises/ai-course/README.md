# Kubernetes for Application Developers

A short course for developers who build applications and now need to run
them on Kubernetes. It takes a learner from a first deployment to an
application that configures itself and recovers on its own.

## Workshops

| Workshop | Type | Title |
| --- | --- | --- |
| `lab-a01-first-deployment` | Core | Your First Deployment |
| `lab-a02-configuration` | Core | Configuration and Secrets |
| `lab-a03-health-checks` | Elective | Health Checks and Self-Healing |

## Layout

- `planning/` holds the course brief, the workshop breakdown, a plan for
  each workshop and the list of outstanding tasks.
- `workshops/` holds one directory per workshop, each an Educates workshop.
