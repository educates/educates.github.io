# Course Brief: Kubernetes for Application Developers

## Course Scope

A focused course of three workshops, in one module. Two core workshops run
in sequence; one elective follows them.

## Audience

Developers who write and ship web applications, and know containers, but
have not deployed to Kubernetes themselves.

## Goals

By the end of the course, a learner can:

- Deploy an application to Kubernetes and expose it to users.
- Move its configuration and credentials out of the image.
- Make it recover on its own when a pod fails.

## Design Principles

- Fully guided: commands run and files change through clickable actions,
  so learners spend their time on Kubernetes, not on typing.
- One application throughout, a small bookshelf web application, so each
  workshop builds on what the learner already deployed.
- Every workshop ends with checks that confirm the learner's work.

## Environment

Each Session gets a namespace with a medium budget, the editor and the
Kubernetes console.
