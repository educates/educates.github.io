# Kubernetes for Application Developers

- `README.md` gives the course overview, its workshops and its layout.
- `planning/course-brief.md` holds the course vision and design principles.
- `planning/resources.md` lists the references gathered while planning;
  read it before searching the web.

## Skills

- Use the **educates-course-design** skill to plan the course, add
  workshops, or update the planning documents.
- Use the **educates-workshop-authoring** skill to create or change a
  workshop from its plan in `planning/workshop-plans/`.

## Design principles

Fully guided: every command and every edit is a clickable action. See
`planning/course-brief.md`.
