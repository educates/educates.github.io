You have built a container image of your application. In this workshop you
run it on Kubernetes, where it keeps running even when a container fails.

## What you will learn

- How a deployment describes the application you want running.
- How a service gives its pods a single address.
- How Kubernetes scales the application and replaces pods that fail.
